# Lionn Magento Modules

Repositório central dos módulos e extensões desenvolvidos pela Lionn Tecnologia para a plataforma Magento 2.

O objetivo deste projeto é centralizar o desenvolvimento, a manutenção e a evolução das extensões próprias, permitindo o seu reaproveitamento em diferentes projetos Magento 2, reduzindo duplicações de código e facilitando a manutenção.

---

<br></br>

## Objetivos

- Centralizar os módulos desenvolvidos pela Lionn.
- Manter uma base de código única para cada módulo.
- Facilitar o reaproveitamento de funcionalidades entre projetos.
- Padronizar a estrutura e a organização das extensões.
- Simplificar as correções, melhorias e atualizações.
- Documentar e manter o histórico do desenvolvimento.

---

<br></br>

## Organização

Cada diretório na raiz representa um módulo independente.

```text
lionn-magento-modules/
│
├── Lionn_AdminLogo/
├── Lionn_BackToTop/
├── Lionn_Exemplo/
│
└── README.md
```

Cada módulo possui a sua própria estrutura e os seus arquivos de configuração, implementação e documentação.

## Projetos

Os módulos deste repositório podem ser utilizados em diferentes projetos mantidos pela Lionn, incluindo:

- **Lionn:** plataforma principal e Infobase.
- **Mage2Bar:** projeto demonstrativo de uma loja Magento 2, voltada para bares.
- **Mage2Tools:** projeto de comércio de ferramentas e soluções para o ecossistema Magento 2.

As cópias dos módulos são mantidas dentro dos respectivos projetos para garantir a sua independência e permitir que cada ambiente tenha as funcionalidades básicas necessárias.

## Manutenção e atualizações

Este repositório é a fonte oficial dos módulos desenvolvidos pela Lionn Tecnologia.

As alterações, correções e melhorias devem ser realizadas com prioridade neste repositório.

Após a validação de uma atualização, os arquivos correspondentes podem ser sincronizados com os projetos que utilizam o módulo.

Personalizações específicas devem ser evitadas sempre que possível, priorizando o reaproveitamento da implementação original.

## Compatibilidade

A compatibilidade de cada extensão depende da versão do Magento 2 (Open Source) / Adobe Commerce e dos requisitos técnicos definidos em seu respectivo diretório.

Consulte a documentação individual de cada módulo para obter informações sobre instalação, configuração, dependências e versões suportadas.
